# Atividade 4 - Calculadora Básica em Python

Este diretório contém os arquivos referentes à quarta atividade, que consiste na criação de uma calculadora interativa que realiza operações matemáticas básicas de acordo com as opções selecionadas pelo usuário.

## Exercício Desenvolvido

1. **Calculadora com Seleção de Operações**: O programa solicita dois números reais e um código de operação para executar o cálculo correspondente:
   - **1 (Soma)**: Soma os dois números.
   - **2 (Subtração)**: Subtrai o segundo número do primeiro.
   - **3 (Multiplicação)**: Multiplica os dois números.
   - **4 (Divisão)**: Realiza a divisão do primeiro número pelo segundo, tratando a divisão por zero (retorna `0`).
   - Caso um valor inválido seja inserido para a operação, o resultado padrão retornado é `0`.

2. **Formatação do Resultado**: Utiliza uma função de formatação para apresentar o resultado de forma limpa: exibe como número inteiro se o resultado for exato, ou substitui o ponto decimal por vírgula para números fracionários.
