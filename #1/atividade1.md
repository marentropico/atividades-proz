# Atividade 1 - Lógica Booleana em Python

Este diretório contém os arquivos referentes à primeira atividade de lógica e expressões booleanas em Python.

## Exercícios Desenvolvidos

1. **Exercício 1**: Avalia se a `nota` (10) é menor ou igual a 10.
2. **Exercício 2**: Verifica se a `nota` (6) é menor ou igual a 6 **e** as `faltas` (4) são menores ou iguais a 3.
3. **Exercício 3**: Verifica se os `convidados` (3) são maiores que 4 **ou** se é `fumante` (False).
4. **Exercício 4**: Verifica se o `dia` ("qua") é igual a "sab" ou "dom".
5. **Exercício 5**: Testa a negação (`not`) da variável `feriado` (True).
6. **Exercício 6**: Verifica se o `dia` ("ter") é igual a "seg" **ou** se não é feriado (False).
