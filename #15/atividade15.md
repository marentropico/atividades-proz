# Atividade 15 - Avaliação de Array de Números da Sorte (JavaScript)

Este diretório contém os arquivos referentes à décima quinta atividade, que consiste em um script em JavaScript para avaliar elementos de um array numérico e imprimi-los no console conforme regras pré-estabelecidas de paridade e magnitude:

- X é par e menor que 50
- X é menor que 50
- X é maior que 50
  numerosDaSorte = [37, 14, 26, 5, 94, 87]

## Código Desenvolvido

O script foi criado no arquivo [index.js] e realiza a iteração e classificação dos elementos do array `numerosDaSorte`:

```javascript
const numerosDaSorte = [37, 14, 26, 5, 94, 87];
```

### Resultados da Execução

Ao executar o código, o console exibe a seguinte saída para cada número correspondente:

- `37 é menor que 50`
- `14 é par e menor que 50`
- `26 é par e menor que 50`
- `5 é menor que 50`
- `94 é maior que 50`
- `87 é maior que 50`
