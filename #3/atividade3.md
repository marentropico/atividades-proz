# Atividade 3 - Estruturas de Repetição em Python

Este diretório contém os arquivos referentes à terceira atividade, que foca na utilização de diferentes estruturas de repetição (laços) para listar os andares de um prédio de 20 andares, ignorando o 13º andar.

## Exercícios Desenvolvidos

1. **Laço `for`**: Utiliza o loop `for` combinado com a função `range(1, 21)` e o comando `continue` para pular o 13º andar.
2. **Laço `while`**: Implementa a contagem de forma condicional com `while`, incrementando manualmente o contador e tratando a exceção do 13º andar.
3. **Simulação de `do-while`**: Simula a estrutura do-while utilizando um laço infinito `while True` com uma condição de parada (`break`) ao ultrapassar o 20º andar.
4. **Desafio - Ordem Decrescente**: Utiliza o laço `for` com passo negativo (`-1`) para imprimir os andares de 20 a 1 em ordem decrescente, também omitindo o 13º andar.
